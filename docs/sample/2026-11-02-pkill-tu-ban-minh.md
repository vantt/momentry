# Agent tự kết liễu shell của mình

Dùng `pkill -f` với một chuỗi để dừng tiến trình đo, chuỗi đó lại nằm trong chính dòng lệnh đang chạy: shell của agent tự bị giết. Chuyện vui nhỏ, có thể làm đoạn chèn.

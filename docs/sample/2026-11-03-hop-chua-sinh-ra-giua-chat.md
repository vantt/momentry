# Hộp chứa chuyện này ra đời giữa một phiên làm việc

Đang duyệt golden set thì user nhận ra chính việc đang làm là chuyện kể được. Hỏi agent có cách nào tự quan sát nhẹ trong phiên để nhặt khoảnh khắc. Ra hai cơ chế: cơ học (khi nào kích hoạt, lưu thế nào) và phán đoán (đáng kể không). User chỉnh: đừng lọc sớm, ghi nhiều và nối trước, lọc sau cùng. Giống chính đường ống capture rồi mới triage của dự án.
